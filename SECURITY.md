# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** action on the repository's Security Advisories page:

<https://github.com/domhutch/POCUS-Logbook/security/advisories/new>

If private vulnerability reporting is unavailable, contact the repository maintainers privately through GitHub and ask for a secure reporting route. Do not include patient data, logbook backups, access tokens, or other sensitive user data in a report.

Include the affected version or commit, the impact, steps to reproduce with synthetic data, and any suggested mitigation. The maintainers will acknowledge the report and coordinate a fix and disclosure with the reporter.

## Scope

This policy covers this repository and the CritSono: POCUS Logbook application. It does not provide a security contact for Google, GitHub Pages, browsers, operating systems, or other third-party services; report issues in those services to their respective maintainers.
